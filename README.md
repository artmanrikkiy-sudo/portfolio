# 🛸 UFOキャッチャー配置図（自動整列・位置保存・点検システム）

UFOキャッチャーのレイアウト変更と、各筐体のテストデータ（設定値）の点検を同時に行えるWebシミュレーターです。
フロントエンドの基礎（HTML/CSS/JavaScript）を組み合わせ、実務での利用を想定した動的なUI/UXを実装しました。

##デモサイトはこちら
https://artmanrikkiy-sudo.github.io/portfolio/

## ✨ 主な機能
1. **ドラッグ＆ドロップによる自由なレイアウト変更**
   - 直感的な操作で筐体の配置を変更できます。
2. **データの永続化（LocalStorage）**
   - 変更した位置情報や点検入力データはブラウザに保存され、ページをリロードしても保持されます。
3. **自動整列アルゴリズム**
   - データの保存がない初期状態では、筐体数に応じて自動で等間隔に横並びへ配置されます。
4. **点検・判定モード**
   - 基準値（3.90）に対する許容誤差（0.08）を自動計算し、基準を超えた筐体を視覚的にアラート（赤色変化）します。

## 🎯 開発背景（作成した理由）
アミューズメント施設における「UFOキャッチャー（クレーンゲーム）の運営効率化」を想定して開発しました。
日々行われる筐体の点検作業において、数値のズレ（異常値）を素早く視覚的に検知し、
さらに店舗内の複雑なレイアウト変更を画面上で直感的にシミュレーション・保存できる仕組みを作ることで、現場のオペレーションの工数削減とミス防止を目指したものです。
まずはPythonでコアとなる判定ロジックを検証し、その後フロントエンドへ展開して実用的なWebシミュレーターへと形にしました。


## 🛠 採用技術・設計のポイント
### 🤖 生成AI（AIコーディング）の活用について
本プロジェクトのフロントエンド開発においては、生成AIを設計や試作の補助として利用し、開発スピードの大幅な向上を図りました。
最終的なコードの理解・整理・修正は自身で行いました。
- **AIを効率的に活用した点**:
  UIのベース設計や、JavaScriptによる複雑なドラッグ＆ドロップイベントのモックアップ作成にAIを活用。
- **エンジニア自身が主導した点（自力の成果）**:
  AIが生成したコードの挙動（DOM操作、LocalStorageの保存ロジック）を理解した上で、構造（HTML）、装飾（CSS）、ロジック（JS）の3つのファイルへ分離し、保守性の高い構成へ組み直しました。
  また、元となる異常検知の計算アルゴリズムは、事前に自身がPython（`data_analysis.py`）で自力構築・検証したロジックをベースに移植しています。
- **HTML5 / CSS3**: Flexboxを用いたレイアウト、CSS Transitionによるスムーズな色の変化。
- **JavaScript (Vanilla JS)**: 外部ライブラリ（jQueryなど）に依存せず、ネイティブなDOM操作とイベントリスナー（MouseDown/Move/Up）のみでドラッグ＆ドロップを軽量に実装。
- **ファイルの関心事の分離（SoC）**: 保守性を考慮し、構造（HTML）、装飾（CSS）、ロジック（JS）を3つのファイルに綺麗に分割して管理。

## 📂 ファイル構成
- `index.html` : 画面の骨組み
- `style.css` : レイアウトおよび筐体のデザイン
- `script.js` : ドラッグ＆ドロップ・データ保存・判定ロジック
- `past-codes/` : 過去の学習用コード一式
